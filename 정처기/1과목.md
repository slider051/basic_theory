## 소프트웨어 설계

클래스 :객체를 만들기 위한 설계도(템플릿)이자, 객체의 속성과 동작을 정의하고 이를 바탕으로 객체를 생성하기 위한 틀이다.

GoF(Gang of Four) 디자인 패턴 : "객체지향 프로그램에서 자주 발생하는 설계 문제를 해결하기 위한 검증된 설계 방법(재사용 가능한 설계 템플릿) 23가지."

- 어댑터(디자인패턴) :  호환되지 않는 인터페이스를 가진 두 객체가 함께 일할 수 없게 만드는 문제를 해결하기 위해 사용
>> 실제 자바에서는 어떻게 쓰이는가?
"""자바에서 List와 Array 간의 변환을 어댑터 패턴의 예시로 들 수 있다. 예를 들어, 배열 형태로 구현된 정렬 알고리즘을 List 객체에 적용하고 싶을 때, 어댑터를 사용하여 List를 Array로 변환하고 정렬 후 다시 Array를 List로 변환하는 방식으로 활용할 수 있다. 복잡한 알고리즘의 경우, 기존 구현을 재사용하는 것이 효율적일 수 있다"""

- 옵저버(행위패턴) : 한 객체의 상태가 바뀌면 여러 객체에게 자동으로 알려준다. (유튜브 구독 - 알림)
